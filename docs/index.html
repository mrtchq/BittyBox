DUAL-STATE ARCHITECTURE

Alive Mode →
Aftermath Mode.

Competitors only “send an email.” BittyBox becomes something else entirely. Each capsule exists in two distinct, independently programmed states:

  • Degraded (Mutating): Visual glitches, escalating alerts, and countdown acceleration if overdue.
  • Aftermath Mode: Unlocks secret vaults, triggers media drops, or deploys permanent digital memorials.

CLIENT-SIDE CRYPTOGRAPHY

PIN codes, expiration
and view limit locks.

Lock your Bitty Page before sharing. All encryption happens client-side with AES-256 GCM in your browser before the URL is created. The server never sees your unencrypted plaintext.

  • Passcode PIN Lock: Protect your page with an 8-12 digit PIN known only to you and your recipient.
  • Time-Based Windows: Set an expiration timer so the page locks automatically when time is up.
  • Burn-After-Reading View Limits: Limit the page to 1 view, 3 views, or custom quota before permanent destruction.
