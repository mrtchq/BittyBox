Bitty Box Remaining-Opens Badge — UI Design

Server-authoritative scarcity badge for a max-opens / one-time locked Box. The value is derived on the server from opensUsed (see buildLockScreen → remainingOpens) and is never computed client-side, so it can't be spoofed to override the gate.

9 opens left 1 open left — last chance Sealed — 0 opens left

State rule: ok when remainingOpens > 1, low (amber warning) when exactly 1, sealed (red, lock icon) when 0 / exhausted === true. Hide the badge entirely when remainingOpens === null (no open-limit lock).

Drop-in render snippet

// lockScreen = response from POST /api/boxes/:id/unlock (denied branch)
function renderOpensBadge(lockScreen) {
  const r = lockScreen.remainingOpens;
  if (r === null || r === undefined) return '';          // no open-limit lock
  if (r <= 0 || lockScreen.exhausted) {
    return `<span class="opens-badge" data-state="sealed">
      <svg class="ico" viewBox="0 0 24 24">…lock…</svg> Sealed — 0 opens left</span>`;
  }
  const state = r === 1 ? 'low' : 'ok';
  const label = r === 1 ? 'open left — last chance' : 'opens left';
  return `<span class="opens-badge" data-state="${state}">
    <svg class="ico" viewBox="0 0 24 24">…star…</svg>
    <span><span class="count">${r}</span> ${label}</span></span>`;
}
