# Build Summary — Password Lock

**Feature:** Client-side zero-knowledge passcode lock for Bitty Box

## What it does
A user can lock any Box behind a passcode. The passcode is never sent to the
server in cleartext — encryption and verification happen entirely in the
browser. Unlock UI adds a physical "shake" animation on a wrong passcode and a
fade-out on successful unlock.

## Security model
- **Zero-knowledge:** passphrase-based key material is derived client-side; the
  server stores only ciphertext + salt, never the passphrase or derived key.
- **Authenticated encryption:** AES-GCM provides confidentiality + tamper
  detection.
- **Key stretching:** PBKDF2 raises the cost of offline brute-force attempts.
