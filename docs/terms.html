2. Serverless Architecture & Payload Responsibility

BittyBox operates on a client-side architecture where capsule payloads (HTML, CSS, JavaScript, media, and data schemas) are compressed, encoded, and decrypted directly inside client web browsers via URL hash fragments.

Because hash fragments are never transmitted to web servers per standard browser HTTP specifications, BittyBox does not host, curate, inspect, or retain your private capsule source code. You assume full responsibility for all payloads generated, shared, or executed through BittyBox.
